## 🚀 Run Anything Here

```bash
git clone https://github.com/Adarshukumar/Python.git
cd Python

# my own lessons
python Python-Learning/01_hello_world.py

# any library project — see its own README and requirements.txt first
cd flasky && pip install -r requirements.txt
```

Python 3 installed is all you need for the lessons. The library folders have their own
dependencies (each keeps its upstream README).
