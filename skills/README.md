# skills/

Agent Skills (open standard: one folder per skill, each with a `SKILL.md`). Works with Claude Code,
GitHub Copilot, Cursor and other agents that read the Agent Skills format.

Generated by `arena-session-3b2d329a/artifacts/build_study_skills.py`, except `agent-skill-security-audit/`,
which is hand-written. Regenerate the study skills with:

```bash
python3 arena-session-3b2d329a/artifacts/build_study_skills.py
```

## Study method skills

| Skill | Use it for |
|---|---|
| `study-method-active-recall` | Study technique that makes the learner retrieve answers from memory instead of rereading notes. |
| `study-method-spaced-repetition` | Scheduling method that reviews material just before it would be forgotten, so it is remembered for longer. |
| `study-method-feynman-technique` | Learning method that tests understanding by explaining a concept in plain language and finding the gaps. |
| `study-method-pomodoro-focus` | Time-management method that splits study into fixed focus blocks with short breaks. |
| `study-method-cornell-notes` | Note-taking layout with three parts: notes, cues and summary. |
| `study-method-interleaved-practice` | Practice method that mixes different problem types in one session so the learner has to choose the right approach. |
| `study-method-past-paper-practice` | Exam preparation method: solving real past papers under timed conditions and marking them against the official scheme. |
| `study-method-exam-day-strategy` | Plan for the day of an exam: time allocation, question order and handling of blanks. |
